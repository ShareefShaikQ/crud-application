# TaskFlow - React + Tailwind CRUD

Responsive task-management CRUD application built with React, Vite and Tailwind CSS.

## Features

- Create tasks
- Read/list tasks
- Edit tasks
- Delete tasks
- Search
- Status and priority filters
- Dashboard statistics
- Responsive desktop/mobile UI
- Browser localStorage persistence
- No backend required for this learning project

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## GitHub + Azure

Push this project to GitHub and connect the repository to Azure App Service using Deployment Center. Azure can build the project and deploy the generated `dist` output.

For a real production CRUD application, replace localStorage operations with REST API calls to an ASP.NET Core/Node backend and store data in SQL Server/PostgreSQL.
